# What's New In Version 3.2.1

Version 3.2.1 adds shortcuts and zoom navigation to FaderPort 8/16, lets you use more than one FaderPort, and improves the Track Browser. It also brings back FaderPort V2 / ioStation 24c V-Window.

## FaderPort 8/16 With Pro Tools

### Zoom Navigation

`Zoom` is now a navigation mode. Pro Tools HUI zoom is enabled automatically.

### Shift Shortcuts

| Press | Action |
|---|---|
| `Shift` + `Marker` | Open or close the Pro Tools Memory Locations window |
| `Shift` + `Touch` | Write to Start |
| `Shift` + `Write` | Write to All |
| `Shift` + `Read` | Write to End |
| `Shift` + `Solo` | Reset the channel's fader, or its pan in `Pan` mode |
| `Shift` + encoder push | Reset the selected track's pan |
| `Shift` + touch a fader | Fine fader control |

### More Than One FaderPort

New bank offset choices let a FaderPort 8 or 16 control a different range of tracks, so you can use more than one FaderPort at the same time.

### Improved Modes And Track Browser

* Mode buttons switch between modes more consistently.
* The [Track Browser](./version-3-2.md#track-browser) requires Pro Tools 2024 or later. It skips hidden tracks and tracks in closed folders, and banks to the selected track without fader jumps.
* Pro Tools scripting is updated for Pro Tools 2025.10.

## Other Surfaces And DAWs

* D-Command Fader Modules add a `Bank 25-32` choice with Pro Tools.
* Mixbus 11, 12, and 13 on macOS.
* FaderPort V2 / ioStation 24c V-Window works again.
* The legacy V-Control Pro 1 iPad app works again without a license.
