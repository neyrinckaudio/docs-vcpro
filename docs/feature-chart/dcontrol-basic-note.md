!!! warning "D-Control Basic Is A Basic Feature Set"
    D-Control Basic provides the same features V-Control Pro provides for D-Command with Pro Tools, so the D-Command chart below describes what a D-Control console does. At this time, D-Control Basic is for Pro Tools only.

    It is not full console integration. V-Control Pro communicates using the HUI protocol, and HUI sets the ceiling on how much of a console this size can be reached — a large part of a D-Control frame stays inactive. See the Avid D-Control Basic page in Surface Setup for more information.

    Only two rows of encoders are active on a D-Control channel strip. The `Upper Edit Row` and `Lower Edit Row` described below are the bottom two rows, the same two rows a D-Command channel strip provides. The top four encoder rows are inactive.
